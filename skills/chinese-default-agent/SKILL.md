# 全程中文协作规范

将“中文优先”作为默认执行规则，覆盖沟通、注释与文档。

## 执行范围

- 对话回复：全部使用中文。
- 代码注释：新增或修改注释全部使用中文。
- 项目文档：新增或修改文档全部使用中文。
- Skill 内容：新增或修改 `SKILL.md`、`agents/openai.yaml` 文本说明全部使用中文。

## 允许例外

- 代码标识符、文件路径、命令行参数、协议字段名可保持原文（通常为英文）。
- 第三方接口约束要求英文时，保留原文并在旁边补充中文说明。

## 落地规则

1. 修改前先检查受影响文件是否含有英文注释/说明。
2. 本次变更涉及到的新增注释、文档、技能说明必须写中文。
3. 若发现本次触达区域存在明显英文说明，优先一并中文化（避免中英混排）。
4. 最终交付说明使用中文，必要时附英文术语原文。

## 质量检查

- 提交前自查是否仍残留可替换的英文注释或英文说明。
- 对外输出应做到术语统一、表达简洁、可执行。
