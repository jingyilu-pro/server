## 禁制

### 基本类型

| 类型 | ID | 效果 | 难度值 | 隐匿值 | 目标

| 行禁 | enterlock | 禁止通过或进入 | - | - | ±等级，±种族，±宗派，例外

| 空禁 | flylock | 禁止飞行 | - | - | ±等级，±种族，±宗派，例外

| 灵禁 | manalock | 法力全无 | - | - | ±等级，±种族，±宗派，例外

| 重禁 | gravitylock | 禁止飞行、加大重力作用 | - | - | ±等级，±种族，±宗派，例外

| 触禁 | touchlock | 禁止碰触、拾取、操作等 | - | - | ±等级，±种族，±宗派，例外

*注：+表示该等级及以上，该种族，该宗派，-表示该等级及以下，除该种族外，除该宗派外*
